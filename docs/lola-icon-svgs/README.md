# LOLA – Leipzig's Open Learning Avatar: logos

## Letters

- Plus Jakarta Sans ExtraBold
- tagline: Inter SemiBold (both SIL Open Font License 1.1).

## Contents
|file name                      | usecase                                                           |
|-------------------------------|-------------------------------------------------------------------|
|lola-logo-en / -de             |main logo with tagline, for light backgrounds                      |
|lola-logo-*-dark-bg            |same, for dark backgrounds                                         |
|lola-logo-en-black / -white    |one colour, for print and stamps (no yellow spark)                 |
|lola-wordmark*                 |LOLA without tagline (use below ~120 px width)                     |
|lola-icon                      |app icon, rounded                                                  |
|lola-icon-square               |full-bleed square (iOS, social media avatars crop it themselves)   |
|lola-icon-small                |simplified for 16-32 px (favicons), no face                        |
|lola-icon-black / -white       |one colour                                                         |
|lola-badge                     |round sticker/seal, English tagline on top, German below           |
